## ③ 架构与代码质量（70/100）

### P1

**AR-P1-1 导航手写 Overlay 栈，进程重建即丢**
`MainActivity.kt:39-41,52-57`：`tab/overlay/detailTx/addPrefill` 全是 `remember`（非 `rememberSaveable`），且手写 `when(overlay)` 而非 Navigation。`navigation.compose` 已在 `app/build.gradle.kts:81` 依赖却 0 使用。
后果：编辑一半接个电话回来，页面回到首页，草稿全丢；返回键/系统手势/深层链接无法统一处理。
修复：二选一 —— （小）全换 `rememberSaveable` + `BackHandler`；（大）迁到 navigation-compose + ViewModel 持 UI 状态。建议先小后大。

**AR-P1-2 全量加载+内存聚合，万笔必卡**
`Ledger.kt:100` `observeAll()` 取全表 → `MainActivity.kt:59` 全局 `collectAsState` → 首页/账单/统计/搜索各做一次 O(N) 过滤聚合。
`StatsScreen.kt:174-185` 近6月趋势是 O(6×N)；`BillListScreen.kt:110-152` `buildItems` 里每笔 `Calendar.getInstance()` 两次（608 笔=2400+ 个 Calendar，万笔直接 GC 抖动）。
修复：① DAO 加 `SUM/GROUP BY` 查询与分页（Paging3 或 LIMIT/OFFSET）；② `buildItems/monthRange` 换 `java.time` 并缓存；③ `all` 按需订阅（各页只拿自己要的 Flow）。3 天，分步做。

**AR-P1-3 ViewModel 正在变成上帝类**
`LedgerViewModel.kt` 203 行管了 db+3 个 Flow+备份防抖+6 组 CRUD。加预算/定期/转账后必破 500 行。
修复：抽 `LedgerRepository`（DAO+Seed+BackupCodec）与 `BackupScheduler`用例，VM 只做状态粘合。2 天。

- **无 DI**：`LedgerDb.get(app)` 全局单例 + DataStore 手写 flow，VM 不可单测（28 用例全是纯函数，VM/DAO 0 覆盖）。引入 Hilt 太重的话，至少给 VM 构造注入 DAO（方便 JVM 测账户兜底顺序）。

先肯定：文件名设备+来源+时间戳、三线归档（latest覆盖+auto/manual只增）、恢复前 safety 留底、按 id 合并、预览确认、防抖只刷 latest —— 这套比很多个人 App 强。

修复：恢复确认弹窗加模式选择［合并/完全替换］，替换即事务内 `DELETE all + INSERT`。0.5 天。

### P1

**DA-P1-1 备份 JSON 无版本号**
`BackupDto`（`Ledger.kt:89-94`）无 `schemaVersion/appVersion`。1.1 加转账/预算字段后，旧包打不开新备份、新包读旧备份全靠 `ignoreUnknownKeys` 蒙。
修复：加 `format: Int = 1` + `appVersion: String`，恢复时按版本迁移/拒收并提示。0.5 天，和 P0-1 同批。

**DA-P1-2 导出三表非同一快照**
`BackupCodec.export:31-33` 三次 `first()` 分开读，导出中途若有写入（防抖 Worker/前台记账并发），三表时间点不一致。
修复：DAO 加 `@Transaction suspend fun snapshot()` 一次读三表，或 `db.withTransaction`。0.5 天。

**DA-P1-3 坚果云凭据明文存 DataStore**
`NutstoreConfig`（以 1.0.3 报告为准已清空默认值，本次未复读凭据文件，按 DataStore 明文假设）：Basic Auth 密码在 prefs 明文。Root/备份文件被拷即泄。
修复：迁到 `EncryptedSharedPreferences`（AndroidX Security）或 DataStore+AEAD，最小解也至少加 `require` 不打日志（已做 `readCreds` 校验，`BackupWorker.kt:60` ✅）。1 天。

**DA-P1-4 失败用户无感知**
Worker 失败只写 `lastResult` 小字 + retry 3 次（`BackupWorker.kt:33-39`），POST_NOTIFICATIONS 已删后，杀后台/断网 3 天用户全然不知。
修复：设置页/备份页红点 + “3 天未成功”横幅，不弹通知也行，但要有应用内强提示。0.5 天。

## ⑥ 产品功能完整度（55/100，竞品对标：鲨鱼/钱迹/一木/MoneyWiz）

> 本节由 agent 实读 `ui/` 28 文件 + `Ledger.kt` 实体 + `migration.json` 产出，摘要如下（人天按单人兼职含 UI+迁移+测试估）。

### 现状边界（实测）

- 记账：支出/收入两段、金额、4 列分类、账户选择（>1 才显）、日期（禁未来）、单行备注

- 导出：CSV 5 列（日期/类型/分类/金额/备注），**无账户列**，无导入
- 实体：`Account(id,name,color,orderNum)` / `Category(id,name,color,orderNum)` / `Tx(id,accountId,isExpense,amountCents,categoryId,note,dateTime)` —— **无转账、无预算、无标签、无附件、无定期、无负债、无币种**
